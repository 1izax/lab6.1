# Домашнее задание к работе 2
## Условие задачи
Проверить, превышает ли 2000 произведение двух натуральных двузначных чисел, введенных пользователем. (Если веденные числа не двухзначные вывести сообщение об ошибке ввода)
## 1. Алгоритм и блок-схема
### Алгоритм решения
1. Начало
2. Объявить константы:
   - первое число: a
   - второе число: b
   - произведение: product
3. Вывести приглашение и ввести с клавиатуры число a
4. Вывести приглашение и ввести с клавиатуры число b
5. Если оба числа не являются двузначными (a < 10 или a > 99 или b < 10 или b > 99):
   - вывести сообщение об ошибке ввода
7. Иначе вычислить произведение:
    - product = a * b
8. Проверить, превышает ли произведение 2000:
   - если product > 2000 → вывести «Да! Произведение больше 2000»
   - иначе вывести «Нет. Произведение не больше 2000»
9. Конец

## 2. Реализация программы
```
#include <stdio.h>
#include <locale.h>

int math()
{
    setlocale(LC_CTYPE, "RUS");

    int a, b, product;

    printf("=== ПРОВЕРКА ПРОИЗВЕДЕНИЯ ===\n");
    printf("Введите первое число: ");
    scanf("%d", &a);
    printf("Введите второе число: ");
    scanf("%d", &b);
    if (a < 10 || a > 99 || b < 10 || b > 99)
    {
        printf("Ошибка! Оба числа должны быть от 10 до 99.\n");
    }
    else
    {
        product = a * b;
        printf("Произведение: %d * %d = %d\n", a, b, product);
        if (product > 2000)
        {
            printf("Да! Произведение больше 2000.\n");
        }
        else
        {
            printf("Нет. Произведение не больше 2000.\n");
        }
    }
}

int main()
{
    math();
    getchar();
    return 0;
}
```
